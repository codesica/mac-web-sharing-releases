# Mac Web Sharing downloads

Public installers for [Mac Web Sharing](https://share.yangluotong.top/). This repository distributes binaries and release notes; product source is maintained separately.

Apple Silicon, macOS 15+. The current release is not Developer ID signed or notarized by Apple. Installation and first-open instructions are on the [download page](https://share.yangluotong.top/en/download/).

Only install files from the release linked by the product website. SHA-256 is provided with every installer. This initial release has not completed clean-machine Gatekeeper or recipient-access acceptance testing.
